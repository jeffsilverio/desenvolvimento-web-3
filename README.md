# Desenvolvimento Web - Aula prática 3

Este é um projeto simples criado para a disciplina *Fundamentos de Desenvolvimento Web*, no segundo semestre do curso de Graduação em Engenharia de Software da Uninter.

O objetivo do projeto é demonstrar conceitos básicos de HTML, CSS e o uso de componentes do Bootstrap, incluindo:

- Uma página principal (index.html) com seções "Sobre nós" e uma galeria/carrossel de imagens.
- Arquivo de estilos personalizado: `estilo.css`.
- Uso de Bootstrap para responsividade e componentes prontos (painéis, carrossel, navbar).

Como visualizar

1. Faça clone ou baixe este repositório.
2. Abra o arquivo `index.html` em um navegador moderno.

Alternativamente, para testar localmente com um servidor HTTP simples (recomendado ao usar recursos que dependem de requisições locais):

- Python 3: `python -m http.server` (abre em http://localhost:8000)

Estrutura do repositório

- index.html — página principal
- estilo.css — estilos personalizados
- bootstrap/ — arquivos do Bootstrap (CSS/JS)
- img/ — imagens usadas no site
- jquery.js — biblioteca jQuery usada pelo Bootstrap
